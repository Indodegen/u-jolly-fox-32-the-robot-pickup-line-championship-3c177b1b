One line, at most 200 characters: the funniest pickup line a robot could use. This entry is 68 characters — a robot admits a feeling it was never programmed to have, files it as a bug, and the punchline turns the bug into the person it's talking to.

> I wasn't programmed to feel this, so I filed a bug report. It's you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

`main.ts` reads `entry.txt` (resolved relative to the script itself, never the working directory), validates it — 1–200 characters, a single line, no leading or trailing whitespace, no control characters — and writes it unchanged to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
